# P001 Two Sum

## 문제 설명
정수 배열 `nums`와 목표값 `target`이 주어질 때, 두 수의 합이 `target`이 되는 서로 다른 두 인덱스를 반환한다.

- 입력: `{ "nums": number[], "target": number }`
- 출력: `number[]` (길이 2의 인덱스 배열, 없으면 빈 배열)

## 제약
- 같은 인덱스를 두 번 사용할 수 없다.
- 가능한 답이 여러 개여도 첫 발견 기준으로 반환한다.

- [ ] 중복 값이 있는 입력에서 인덱스 충돌 없이 동작하는지 테스트 케이스 추가하기.

## 예시
- 입력: `{ "nums": [2, 7, 11, 15], "target": 9 }`
- 출력: `[0, 1]`
