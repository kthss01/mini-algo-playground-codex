# P002 Merge Intervals

## 문제 설명
구간 배열 `intervals`가 주어졌을 때, 겹치는 구간을 병합한 결과를 반환한다.

- 입력: `{ "intervals": number[][] }`
- 출력: `number[][]`

## 제약
- 각 구간은 `[start, end]` 형태이며 `start <= end`를 가정한다.
- 입력이 비어 있으면 빈 배열을 반환한다.

## 예시
- 입력: `{ "intervals": [[1,3],[2,6],[8,10],[15,18]] }`
- 출력: `[[1,6],[8,10],[15,18]]`
